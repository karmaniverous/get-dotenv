getdotenv v<VERSION>


Usage: getdotenv [options] [command]

Process dotenv files in an arbitrary location & optionally populate environment
variables.

Options:
  -a, --exclude-all                   exclude all dotenv variables from loading
                                      ON (anywhere: --getdotenv-exclude-all)
  -A, --exclude-all-off               exclude all dotenv variables from loading
                                      OFF (default) (anywhere:
                                      --getdotenv-exclude-all-off)
  -e, --env <string>                  target environment (dotenv-expanded)
                                      (anywhere: --getdotenv-env)
  -g, --exclude-global                exclude global dotenv variables from
                                      loading ON (anywhere:
                                      --getdotenv-exclude-global)
  -G, --exclude-global-off            exclude global dotenv variables from
                                      loading OFF (default) (anywhere:
                                      --getdotenv-exclude-global-off)
  -h, --help                          display help for command
  -l, --log                           console log loaded variables ON (anywhere:
                                      --getdotenv-log)
  -L, --log-off                       console log loaded variables OFF (default)
                                      (anywhere: --getdotenv-log-off)
  -n, --exclude-env                   exclude environment-specific dotenv
                                      variables from loading ON (anywhere:
                                      --getdotenv-exclude-env)
  -N, --exclude-env-off               exclude environment-specific dotenv
                                      variables from loading OFF (default)
                                      (anywhere: --getdotenv-exclude-env-off)
  -o, --output-path <string>          consolidated output file
                                      (dotenv-expanded) (anywhere:
                                      --getdotenv-output-path)
  -p, --load-process                  load variables to process.env ON (default)
                                      (anywhere: --getdotenv-load-process)
  -P, --load-process-off              load variables to process.env OFF
                                      (anywhere: --getdotenv-load-process-off)
  -r, --exclude-private               exclude private dotenv variables from
                                      loading ON (anywhere:
                                      --getdotenv-exclude-private)
  -R, --exclude-private-off           exclude private dotenv variables from
                                      loading OFF (default) (anywhere:
                                      --getdotenv-exclude-private-off)
  -s, --shell [string]                command execution shell, no argument for
                                      default OS shell or provide shell string
                                      (default /bin/sh) (anywhere:
                                      --getdotenv-shell)
  -S, --shell-off                     command execution shell OFF (anywhere:
                                      --getdotenv-shell-off)
  -u, --exclude-public                exclude public dotenv variables from
                                      loading ON (anywhere:
                                      --getdotenv-exclude-public)
  -U, --exclude-public-off            exclude public dotenv variables from
                                      loading OFF (default) (anywhere:
                                      --getdotenv-exclude-public-off)
  -v, --vars <string>                 extra variables expressed as delimited
                                      key-value pairs (dotenv-expanded):
                                      KEY1=VAL1 KEY2=VAL2 (anywhere:
                                      --getdotenv-vars)
  -V, --version                       output the version number (anywhere:
                                      --getdotenv-version)
  -z, --exclude-dynamic               exclude dynamic dotenv variables from
                                      loading ON (anywhere:
                                      --getdotenv-exclude-dynamic)
  -Z, --exclude-dynamic-off           exclude dynamic dotenv variables from
                                      loading OFF (default) (anywhere:
                                      --getdotenv-exclude-dynamic-off)
  --capture                           capture child process stdio for commands
                                      (tests/CI) (anywhere: --getdotenv-capture)
  --debug                             enable debug logging to stderr ON
                                      (anywhere: --getdotenv-debug)
  --debug-off                         enable debug logging to stderr OFF
                                      (default) (anywhere:
                                      --getdotenv-debug-off)
  --default-env <string>              default target environment (anywhere:
                                      --getdotenv-default-env)
  --default-env-key <string>          env var name in global dotenv files that
                                      specifies the default environment
                                      (dotenv-expanded) (anywhere:
                                      --getdotenv-default-env-key)
  --dotenv-token <string>             dotenv-expanded token indicating a dotenv
                                      file (anywhere: --getdotenv-dotenv-token)
  --dynamic-path <string>             dynamic variables path (.js or .ts; .ts is
                                      auto-compiled when esbuild is available,
                                      otherwise precompile) (anywhere:
                                      --getdotenv-dynamic-path)
  --entropy-min-length <number>       min length to examine for entropy (default
                                      16) (anywhere:
                                      --getdotenv-entropy-min-length)
  --entropy-threshold <number>        entropy bits/char threshold (default 3.8)
                                      (anywhere: --getdotenv-entropy-threshold)
  --entropy-warn                      enable entropy warnings (default on)
                                      (anywhere: --getdotenv-entropy-warn)
  --entropy-warn-off                  disable entropy warnings (anywhere:
                                      --getdotenv-entropy-warn-off)
  --entropy-whitelist <pattern...>    suppress entropy warnings when key matches
                                      any regex pattern (anywhere:
                                      --getdotenv-entropy-whitelist)
  --paths <string>                    dotenv-expanded delimited list of paths to
                                      dotenv directory (anywhere:
                                      --getdotenv-paths)
  --paths-delimiter <string>          paths delimiter string (anywhere:
                                      --getdotenv-paths-delimiter)
  --paths-delimiter-pattern <string>  paths delimiter regex pattern (anywhere:
                                      --getdotenv-paths-delimiter-pattern)
  --private-token <string>            dotenv-expanded token indicating private
                                      variables (anywhere:
                                      --getdotenv-private-token)
  --redact                            presentation-time redaction for
                                      secret-like keys ON (anywhere:
                                      --getdotenv-redact)
  --redact-off                        presentation-time redaction for
                                      secret-like keys OFF (anywhere:
                                      --getdotenv-redact-off)
  --redact-pattern <pattern...>       additional key-match regex patterns to
                                      trigger redaction (anywhere:
                                      --getdotenv-redact-pattern)
  --strict                            fail on env validation errors
                                      (schema/requiredKeys) (anywhere:
                                      --getdotenv-strict)
  --trace [keys...]                   emit diagnostics for child env composition
                                      (optional keys) (anywhere:
                                      --getdotenv-trace)
  --vars-assignor <string>            vars assignment operator string (anywhere:
                                      --getdotenv-vars-assignor)
  --vars-assignor-pattern <string>    vars assignment operator regex pattern
                                      (anywhere:
                                      --getdotenv-vars-assignor-pattern)
  --vars-delimiter <string>           vars delimiter string (anywhere:
                                      --getdotenv-vars-delimiter)
  --vars-delimiter-pattern <string>   vars delimiter regex pattern (anywhere:
                                      --getdotenv-vars-delimiter-pattern)

Plugin options — cmd:
  -c, --cmd <command...>              alias of cmd subcommand; provide command
                                      tokens (variadic) (anywhere:
                                      --getdotenv-cmd)

Commands:
  cmd [command...]                    Execute command according to the --shell
                                      option, conflicts with --command option
                                      (default subcommand)
  batch [options] [command...]        Batch command execution across multiple
                                      working directories.
  aws [options] [args...]             Establish an AWS session and optionally
                                      forward to the AWS CLI
  init [options] [dest]               Scaffold getdotenv config files and a
                                      host-based CLI skeleton.
